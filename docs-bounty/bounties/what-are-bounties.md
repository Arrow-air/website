# What are Bounties?

Bounties are paid tasks open to anyone in the Arrow community. They're how Arrow gets real work done — from hardware design to software tooling to community content — without a traditional hiring process.

## How it works

Each bounty is a scoped piece of work with a defined deliverable, a reward in USDC and $ARROW, and an expiry date. Anyone can claim a bounty, complete the work, and get paid on approval.

Every bounty is tagged with the [contributor disciplines](/docs/community/disciplines)
it calls for — the same tags contributors use on the
[contributor map](/docs/community/contributor-map). Bounties are grouped on the
board by discipline category:

- **Engineering** — design & build the aircraft: mechanical, CAD, electrical, aero, power, propulsion
- **Flight Systems** — the brains in the air: firmware, software, controls, autonomy, telemetry, simulation
- **Flight Ops** — fly, test & keep them flying: piloting, flight test, maintenance, support
- **Manufacturing** — make & ship real parts: 3D printing, machining, composites, assembly, sourcing
- **Design / Content / Growth** — how Arrow looks, teaches, and grows: graphics, docs, media, marketing, community
- **Local** — run Arrow where you live: meetups, workshops, vertiport concept work
- **Operations** — run the DAO machinery: governance, tokenomics, coordination, legal, tooling

## Who can participate

Bounties are open to everyone. You don't need to be a long-term contributor or hold any role in the DAO. If you have the skills to complete the work, you can claim it.

Some bounties require specific tools or domain knowledge — read the outline carefully before claiming.

## What you'll earn

Every bounty pays out in two forms:

- **USDC** — stablecoin paid to your wallet within 5 business days of approval
- **$ARROW** — the Arrow governance token, giving you a voice in the DAO

Reward sizes reflect the scope and complexity of the work. Larger, more technical bounties pay more.

## Getting started

Browse the [Active Bounties](/bounty) board to see what's currently open. Filter by skill area to find work that matches your background. When you find something interesting, read the GitHub outline linked in the bounty — it contains the full requirements and acceptance criteria.

Ready to claim? See [How to Claim](./how-to-claim) for the step-by-step process.
