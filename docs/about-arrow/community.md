# Community

Arrow is a community of **optimistic builders** who believe the sky should be open to everyone. We're designing open-source aircraft, deploying them in the real world, and proving that a more collaborative future isn't just possible — it's already being built.

We're not a company with employees. We're a network of people who show up because they believe in where this is going. Some write code from their kitchen tables. Others host meetups at makerspaces. Some are already flying drones commercially and want to shape what comes next. **All of these are valid paths in**, and all of them connect.

## // HOW WE BUILD

Some of us are **Builders** — the distributed engine designing airframes, writing flight software, and imagining use cases that don't exist yet. They push ideas forward in [Discord](https://discord.gg/arrow) threads at midnight and [GitHub](https://github.com/Arrow-air) pull requests on weekends.

Others need to be in the room. They start **Local chapters**, host build days, and create the spaces where strangers become collaborators. This is often where it clicks — where the abstract becomes real. It's also the on-ramp. Most of our core contributors started at a meetup.

And then there are the **Operators**: people taking Arrow's designs and deploying them in the real world. Agricultural surveys, mapping, inspection — actual businesses built on open-source aircraft. Javelina Works in West Texas is the first. We want hundreds more.

These aren't separate tracks. They're a flywheel. Builders create, Local chapters test, Operators deploy, and **field learnings flow back** to make everything better. It compounds.

## // JOIN US

If there's one belief that unites Arrow, it's this: **we're not waiting for permission**. The future we want is worth building, and we're the ones building it.

Start anywhere. [Join Discord](https://discord.gg/arrow). Show up. Build together.
