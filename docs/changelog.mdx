## July 29, 2026

The community-approved contributor disciplines taxonomy, nine categories and forty-three disciplines, is now wired through the whole pipeline: the bounty issue form, the board filters, and the contributor map schema all draw from one canonical list.

**Updated**
- Bounty issue form offers the full taxonomy as `Category: Discipline` checkboxes.
- Bounty board filters by category, discipline, reward, and status, with category-colored discipline pills.
- Contributor map profiles use the same discipline list, which is what makes future matching possible.
