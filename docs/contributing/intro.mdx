# Getting Started

The best way to get connected with the Arrow community and start contributing is to join our Discord server!

Introduce yourself in the `#general` channel and we'll be happy to get you up to speed — we're a friendly bunch.

:::tip Culture Note
You don't need formal permission to start working on anything. However, it's best to communicate with the community to stay aligned and focus on high-impact tasks.
:::

## Collaboration

### [Discord](https://discord.com/invite/arrow)

Discord is where we hang out, exchange ideas, schedule meetings, and coordinate work. It's the best place to keep up with Arrow's development and meet other contributors. All of our meetings happen through Discord — join them!

### [GitHub](https://github.com/Arrow-air)

Everything we build is open source. Hardware designs, software, and documentation all live in our repositories. See the [Development Guide](./guides/development-guide.md) for contribution workflows.

### [DAO Forum](https://dao.arrowair.com)

The DAO forum is where governance happens and where grants and bounties are coordinated. If you have an idea for a project or want to take on funded work, this is where to propose it.

## Getting Involved

### Grants & Bounties

We fund contributor work through grants and bounties coordinated on the [DAO forum](https://dao.arrowair.com). If you have an idea that would benefit Arrow, pitch it there. We'll work with you to define scope, milestones, and compensation.

**Current focus areas:**
- [Project Quiver](/project-quiver) attachment development
- Documentation and guides
- Flight testing and validation
- Manufacturing and assembly tooling

Check the forum for active proposals and opportunities.

### Project Commitment

For ongoing project work, compensation is coordinated at the project level through project leads. If you're interested in deeper involvement with a specific project, start by contributing through grants or bounties to get integrated with the team, then talk to the relevant project lead about commitment arrangements.

## Contributor Pages

Want to add your contributor page? You can do it yourself:

1. Copy the [contributor template](https://raw.githubusercontent.com/Arrow-air/website/main/docs/contributing/contributors/_template.md)
2. Go to the [contributors directory on GitHub](https://github.com/Arrow-air/website/tree/main/docs/contributing/contributors)
3. Select **Add file** → **Create new file**
4. Paste and fill out the template with your information
5. Create a PR from a new branch
6. Once reviewed and approved, your page will go live
