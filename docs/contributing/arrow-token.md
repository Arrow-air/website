Every Arrow grant or bounty includes at least 10% of its value in $ARROW, Arrow DAO's governance token ([AIP-004](https://github.com/Arrow-air/dao-aips/blob/main/AIPs/AIP-004.md)). The token portion is priced at a $0.30 reference with a 1.5× multiplier — so taking compensation in $ARROW stretches further than the equivalent USDC.

**As a contributor, $ARROW gives you:**

- **A vote.** 1 $ARROW = 1 vote on [Snapshot](https://snapshot.org/#/s:arrowair.eth) — project approvals, treasury decisions, governance. Vested tokens count.
- **Ownership.** The people building Arrow's aircraft hold the token that governs the DAO.
- **Manufacturing access.** Community manufacturers post $ARROW bonds to build and sell Arrow-designed hardware under [AIP-009](https://github.com/Arrow-air/dao-aips/blob/main/AIPs/AIP-009.md).

Contributor $ARROW is issued through on-chain vesting contracts on Optimism. If a grant is cancelled, vested tokens are yours and unvested tokens return to the treasury.

Supply is fixed at 100,000,000 with no minting. For the full framework — supply, utilities, treasury deployment, and roadmap — see [The $ARROW Token](../governance/arrow-token) in the governance docs and [AIP-010](https://github.com/Arrow-air/dao-aips/blob/main/AIPs/AIP-010.md).
