# Governance

Arrow is structured as a Decentralized Autonomous Organization (DAO) on the Ethereum blockchain. Decisions about the organization's direction, treasury, and projects are made collectively by token holders through a transparent, on-chain governance process.

## How It Works

- **Propose**: Anyone can draft an Arrow Improvement Proposal (AIP) to suggest changes to the organization.
- **Discuss**: Proposals are discussed openly on the [DAO forum](https://dao.arrowair.com/).
- **Vote**: Token holders vote on proposals via [Snapshot](https://snapshot.box/#/s:arrowair.eth).
