# Core Governance

These documents define the rules, structure, and assets that underpin Arrow DAO. Together they establish who holds decision-making power, how value is stored and distributed, and the legal context in which Arrow operates.

- **Constitution** — The foundational rules governing the DAO
- **Legal** — Legal structure and considerations
- **Arrow Token** — The $ARROW token: purpose, distribution, and governance role
- **Treasury** — DAO holdings and how funds are managed
