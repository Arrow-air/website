## Useful Links

**[Discord](https://discord.com/invite/arrow)** — Day-to-day community chat, meetings, and coordination. The fastest way to get oriented.

**[GitHub](https://github.com/Arrow-air)** — All open source code and hardware designs. Everything is public.

**[DAO Forum](https://dao.arrowair.com)** — Governance proposals, grants, bounties, and project discussions.

**[Snapshot](https://snapshot.org/#/s:arrowair.eth)** — On-chain voting for ARROW token holders.

**[YouTube](https://www.youtube.com/@ArrowAir)** — Flight test footage, build videos, and community updates.

**[Bounty Board](/bounty)** — Browse open bounties and claim rewards in ARROW tokens or USDC.
