# Snapshot (DAO Votes)

Arrow's governance votes happen on [Snapshot](https://snapshot.org/#/s:arrowair.eth), token-weighted and public. Anyone can read every proposal and result; $ARROW holders can vote. Voting is gasless, so casting a vote costs nothing.

## How voting works

- **Who can vote:** anyone holding $ARROW at the block the proposal snapshots. Vesting contributors vote through the vesting factory, which counts vested tokens toward voting weight.
- **How to vote:** connect a wallet at the [Arrow Snapshot space](https://snapshot.org/#/s:arrowair.eth), open the proposal, pick a choice, sign. No gas, no transaction.
- **What gets voted on:** AIPs, project proposals and budgets, elections, and anything else the [governance process](/docs/governance/aips) sends to a vote.

New proposals are announced in [Discord](https://discord.com/invite/arrow) and discussed on the [DAO Forum](https://dao.arrowair.com) before they reach a vote, so a vote should never be the first time you hear about an idea.
