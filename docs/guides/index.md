# Guides

These guides cover the practical side of contributing to Arrow. If you're new, read them roughly in this order: sign the CLA, get set up on Discord and GitHub, then pick up the development guide when you're ready to open a pull request.

## Getting set up

- **[Sign the CLA](/docs/guides/sign-cla)**: the Contributor License Agreement you sign once before your first contribution is merged.
- **[Discord Guide](/docs/community/discord-guide)**: how Discord works and a map of Arrow's server, including where each project talks.
- **[GitHub Guide](/docs/guides/github-guide)**: GitHub from scratch, plus how Arrow uses issues, pull requests and reviews.

## Building

- **[Development Guide](/docs/guides/development-guide)**: Arrow's Git workflow, commit signing and build tooling.
- **[Code Style Guides](/docs/guides/style-guides)**: conventions for Python and TypeScript in Arrow repos.
- **[Writing Style Guide](/docs/guides/style-guides/writing)**: how Arrow's docs are written, for anyone editing these pages.
- **[Brand Guidelines](/docs/contributing/arrow-brand)**: logos, colours and how to use them.

## Working together

- **[Working Async](/docs/community/working-async)**: how a community spread across time zones keeps work moving.
- **[Code of Conduct](/docs/guides/code-of-conduct)**: how we expect people to treat each other.

Something missing? Open an issue on the [website repo](https://github.com/Arrow-air/website/issues) or raise it in Discord.
