# Contributor Disciplines

Arrow uses one shared list of **contributor disciplines** — the things people
actually work on, from CAD to composites to community — everywhere a skill tag
appears:

- **[Bounty board](/bounty)** — every bounty is tagged with the disciplines it
  calls for, and the board's categories are the discipline categories below.
- **[Contributor map](/docs/community/contributor-map)** — when you put
  yourself on the map, you pick up to 3 disciplines for your profile card.
- **Project tooling** — matching open work to the people who can do it.

One taxonomy means the tags always line up: if a bounty is tagged
**Manufacturing: Composites**, it's speaking the same language as every
contributor who registered Composites on the map.

## The taxonomy

Nine categories, each with a handful of disciplines. Tags are deliberately
broad — they describe *what kind of work it is*, not seniority or specific
tools.

## How it's used

**Tagging a bounty.** The [bounty issue form](/bounty/creating-bounties) offers
the full discipline list as checkboxes. Pick the disciplines a contributor
would need to complete the work — usually 1–3, occasionally more for
cross-cutting tasks.

**Registering on the map.** The `/new-contributor` Discord command asks for up
to 3 disciplines. Pick the ones you actually want to be found for — they're
how other contributors (and future matching tools) discover you.

**Changing the taxonomy.** The list is community-approved and versioned. It is
deliberately stable — bounties, contributor profiles, and tooling all reference
it — so additions or renames go through a community review, not a quick PR. If
you think a discipline is missing, raise it in the
[Arrow Discord](https://discord.com/invite/arrow).
