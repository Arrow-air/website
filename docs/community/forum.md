# DAO Forum

The [DAO Forum](https://dao.arrowair.com/) is where Arrow writes down the things that need to last. Discord is great for quick questions and day-to-day chat, but a decision that only lives in a Discord scroll is hard to find a month later. The forum is the public record for anything the DAO has to discuss, agree on or vote on.

## What gets posted there

- **AIP discussions.** Every Arrow Improvement Proposal gets a forum thread during its Review stage, so the community can ask questions and suggest changes before it goes to a vote. See [Submit an AIP](/docs/governance/aips/submit-an-aip).
- **Project proposals.** Under [AIP-006](https://github.com/Arrow-air/dao-aips/blob/main/AIPs/AIP-006.md), every new project is discussed on the forum before it starts. The thread covers scope, how the project fits Arrow's mission, budget and timeline.
- **Monthly project updates.** Each project lead posts a progress update every month, with a sentiment poll so the DAO can say how it thinks the project is going. These updates are the easiest way to follow what each project is doing. The current projects are listed on [Active Projects](/docs/governance/active-project-list).
- **Votes before they reach Snapshot.** Anything heading to a [Snapshot](/docs/reference/snapshot) vote is talked through on the forum first, so a vote is never the first time you hear about an idea.

## How to take part

Anyone can read the forum without an account. To post or reply, sign up at [dao.arrowair.com](https://dao.arrowair.com/).

- **Read the whole thread before replying.** Proposals often change during discussion, and the latest version may already answer your question.
- **Be specific.** "I'd lower the budget for X because of Y" helps an author more than general support or general doubt.
- **Move decisions out of Discord.** If a Discord conversation turns into something the DAO needs to decide, start a forum thread and link it back in Discord so others can follow.

New to proposals? Start with [how AIPs work](/docs/governance/aips) and the [Glossary](/docs/reference/glossary).
