Arrow Improvement Proposals (AIPs)

AIPs are the formal process for proposing changes to Arrow's operations, governance, and protocol. They ensure structured, transparent development of the Arrow ecosystem.

Operational

Changes affecting day-to-day operations for Arrow DAO contributors and Pods

Governance

Improvements related to Arrow DAO governance structure and processes

Protocol

Technical improvements requiring core contract changes or protocol design updates

Informational

General guidelines and information for the Arrow community

How It Works

1

Proposal

Community members draft AIPs following the template and submit via GitHub pull request

2

Review

Community discusses and refines the proposal. A sentiment poll gauges initial support

3

Vote

Arrow token holders vote on Snapshot. Voting power is proportional to token holdings

4

Implementation

Approved proposals move to implementation, ensuring the community's voice shapes Arrow's future
